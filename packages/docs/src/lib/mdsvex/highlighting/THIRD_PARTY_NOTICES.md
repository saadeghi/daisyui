# TextMate grammar notices

The syntax highlighter includes normalized TextMate grammar data from the pinned upstream
sources below. `grammar-manifest.json` contains the source commit and SHA-256 for every
stored grammar. License links are the upstream license references available for each
snapshot; `NOASSERTION` means that the upstream grammar metadata did not provide an SPDX
identifier.
