## Give Claude Code reusable design rules

Claude Code can build complete frontend features inside your repository. daisyUI gives it a stable component vocabulary, theme-aware classes, and design guidance it can reuse without filling each prompt with CSS rules.

## Choose a setup method

- [Skill](/docs/skill/claude-code/): Add reusable daisyUI instructions to Claude Code.
- [Plugin](/docs/plugin/claude-code/): Use the plugin installation method to add the daisyUI skill.
- [MCP](/docs/mcp/claudecode/): Connect tools that supply daisyUI context during a task.

Your application also needs [daisyUI CSS installed](/docs/install/).
