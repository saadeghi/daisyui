## Give Codex reusable UI context

Codex can inspect and edit your frontend, but it still needs a clear component system. daisyUI gives Codex reusable component names, theme rules, and interface patterns instead of repeated styling instructions.

## Choose a setup method

- [Skill](/docs/skill/codex/): Add reusable daisyUI instructions to Codex.
- [Plugin](/docs/plugin/codex/): Use the plugin installation method to add the daisyUI skill.
- [MCP](/docs/mcp/codex/): Connect tools that supply daisyUI context during a task.

Your application also needs [daisyUI CSS installed](/docs/install/).
